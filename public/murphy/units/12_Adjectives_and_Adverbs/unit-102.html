Unit 102 • Adjectives and adverbs

so and suchso + adjective/adverb vs such + (a/an) + adjective + noun; so … that & such … that

We use 'so' before adjectives and adverbs, and 'such' before nouns (or adjective + noun). Both words intensify meaning and can be followed by 'that' clauses to express result.

Learning Objectives

After completing this unit, you will be able to:

  • Use so + adjective / adverb (so tired, so quickly).
  • Use such (a/an) + (adjective) + noun (such a stupid story, such nice people).
  • Form result clauses with so … (that) and such … (that).
  • Differentiate equivalent intensifiers: so long vs such a long time; so far vs such a long way; so much vs such a lot.

Part A — Theory

Part A: So vs Such

so + adjective / adverb

so stupid • so quick • so nice • so quickly

I didn't like the book. The story was so stupid.
Everything happened so quickly.
I've had a busy day. I'm so tired. (= really tired)
He talks so quietly.

such + (adjective) + noun

such a story • such people • such a stupid story

It was such a stupid story. (not a so stupid story)
They are such nice people. (not so nice people)
We had such a good time.
You're such an optimist.

Note: We say such a … (never a such): such a big dog • such an expensive phone.

Part B: Result Clauses: So … that • Such … that

We can use that (or omit it) to show the consequence:

I was so tired that I fell asleep in the armchair.
(or: I was so tired I fell asleep.)

It was such nice weather that we spent the whole day on the beach.
(or: It was such nice weather we spent …)

Part C: So and Such Meaning 'Like This'

So and such can also mean 'to this extent' or 'of this kind':

Somebody told me the house was built 100 years ago. I didn't realise it was so old. (= as old as it is)
I didn't realise it was such an old house.
You know it's not true. How can you say such a thing? (= a thing like this)
Note the idiom: There's no such word. (= that word does not exist)

Part D: Compare Pairings

so long: I haven't seen her for so long.
so far: I didn't know it was so far.
so much / many: There was so much traffic.

such a long time: … for such a long time.
such a long way: … was such a long way.
such a lot (of): … was such a lot of traffic.
