Unit 84 • Pronouns and determiners

there … and it …there is/was, there will be vs it is/was (existence vs specific reference, weather, time, distance)

We use 'there' when introducing the existence of something for the first time. We use 'it' for a specific thing, situation, distance, time, and weather.

Learning Objectives

After completing this unit, you will be able to:

  • Understand when to introduce new entities with there … versus referring to specific items with it ….
  • Use modal structures with there: there will be, there must be, there used to be, there's sure to be.
  • Use it as a dummy subject for adjectives + infinitives: It's dangerous to walk in the road.
  • Use it for distance, time, and weather: It's 10 miles; It's raining; It was windy vs There was a cold wind.

Part A — Theory

Part A: There … vs It … (First Mention vs Specific Reference)

Study this example:

‘There's a new restaurant in Hill Street.’
‘Yes, I know. I've heard it's very good.’

We use there … when we talk about something for the first time, to state that it exists:

There's a new restaurant in Hill Street.
I'm sorry I'm late. There was a lot of traffic. (not It was a lot of traffic)
Things are very expensive now. There has been a big rise in the cost of living.

It = a specific thing, place, fact, or situation previously mentioned:

We went to the new restaurant. It's very good. (It = the restaurant)
I wasn't expecting her to call me. It was a complete surprise. (It = that she called)
there (existence)

I like this town. There's a lot to do here.
The house is empty. There's nobody living there. (there = in that place)

it (specific place / fact)

It's an interesting place.
I like this house. It's very spacious.

Part B: Modal and Aspectual Structures with There

You can use there with modals, semi-modals, and aspectual forms:

there will be
there must be
there might be
there must have been
there should have been
there would have been
there is sure to be
there is bound to be
there is going to be
there used to be
‘Is there a flight to Rome tonight?’ ‘There might be. I'll check online.’
If people drove more carefully, there wouldn't be so many accidents.
I could hear music coming from the house. There must have been somebody at home.
There's bound to be a cafe somewhere near here. (= There's sure to be …)

Compare there and it with modal expressions:

They live on a busy road. There must be a lot of noise from the traffic.
There used to be a cinema here, but it closed.
There's sure to be a flight to Rome tonight.

They live on a busy road. It must be very noisy. (It = living there)
That building is now a shop. It used to be a cinema. (It = the building)
There's a flight tonight, but it's sure to be full. (it = the flight)

Part C: It + Adjective + to … & Distance, Time, Weather

We use it as preparatory subject:

It's dangerous to walk in the road. (not To walk in the road is dangerous)
It didn't take us long to get here.
It's a shame (that) you can't come to the party.
It's not worth waiting any longer.

We also use it to talk about distance, time, and weather:

How far is it from here to the airport?
It's a long time since we last saw you.
It's 10 o'clock. / It's Monday today.

Compare weather descriptions with it and there:

It was windy.  but  There was a cold wind.
It's raining.  but  There's a lot of rain.
