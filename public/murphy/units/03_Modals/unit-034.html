Unit 34 • Tenses Basics

should 2Subjunctive clauses and formal conditions

Learn how to use should after verbs like suggest and insist, and in formal conditions like Should anyone ask.

Learning Objectives

After completing this unit, you will be able to:

  • Use should after verbs like demand, insist, propose, recommend, suggest (or use subjunctive / simple present).
  • Use should after adjectives like strange, surprising, natural, essential.
  • Use If it should happen / Should it happen for formal conditional clauses.

Part A — Theory

A. should after suggest, recommend, insist etc.

You can use should after verbs like demand, insist, propose, recommend, suggest:

  • I insisted that he should apologise.
  • What do you suggest we should do?

You can also omit should (using the base form / subjunctive or past form):

  • I insisted that he apologise. (or apologised)
  • What do you suggest we do?

B. should after adjectives: strange, typical, natural etc.

  • It's strange that he should be late. He's usually on time.
  • I was surprised that she should say such a thing.

C. If ... should ... and Should it happen ...

We can use should in if-clauses to make the condition more unlikely:

  • If you should see Tom, tell him to call me.
  • Should you see Tom, tell him to call me. (formal inversion without 'if')

Key Takeaways for Unit 34

Category Rule Correct Example
