Unit 39 • if and wish

if I knew … I wish I knew …Imagining present situations and expressing regrets with wish

Study how to talk about imaginary present situations and how to express regrets using if + past and I wish.

Learning Objectives

After completing this unit, you will be able to:

  • Use if + past to imagine situations contrary to present facts.
  • Express regrets about present situations using I wish + past simple.
  • Apply were and was interchangeably after if and wish.
  • Use could within conditional and wish clauses to describe desired abilities.

Part A — Theory

A. Imagining Present Situations (if + past)

Study this example situation:

Situation Sarah wants to phone Paul, but she can't do this because she doesn't know his number. She says:
“I'd phone him if I knew his number.” (I'd phone = I would phone)

Sarah does not know Paul's number, so she says ‘if I knew’. When we imagine a present situation like this, we use if + past (if I knew / if you were / if we didn't etc.), but the meaning is present, not past:

  • There are many things I'd like to do if I had more time. (but I don't have time)
  • If I didn't want to go to the party, I wouldn't go. (but I want to go)
  • If you were in my position, what would you do?
  • It's a pity he can't drive. It would be useful if he could.

B. I wish + past for Present Regrets

We use the past in the same way after wish (I wish I knew / I wish you were / I wish I didn't etc.). We use wish to say that we regret something, that something is not as we would like it to be:

  • I wish I knew Paul's phone number. (= I don't know it, and I regret this)
  • Do you ever wish you could fly? (you can't fly)
  • It's very crowded here. I wish there weren't so many people. (there are a lot of people)
  • I wish I didn't have to work tomorrow, but unfortunately I do.
Glad (Fact)

I'm glad I live here. (= I live here and that is good)

Wish (Regret)

I wish I lived here. (= I don't live here, unfortunately)

C. Were vs. Was • No 'would' after if/wish

After if and wish, you can use were instead of was with all pronouns (if I were / if he were / I wish it were):

  • If I were you, I wouldn't buy that coat. (or: If I was you...)
  • I'd go for a walk if it weren't so cold. (or: ...if it wasn't so cold)
  • I wish Anna were here. (or: I wish Anna was here)
Important We do NOT say ‘if ... would’ or ‘wish ... would’ when expressing present states:
  • If I were rich, I would travel a lot. (NOT If I would be rich)
  • I wish I had something to read. (NOT I wish I would have)

Part B — Exercises

Exercise 39.1 12 items • Put the verb into the correct form

Put the verb into the correct form (past simple or would + base form).

  1. If I (I / know) his number, I would phone him.
  2. (I / not / buy) that coat if I were you.
  3. (I / help) you if I could, but I'm afraid I can't.
  4. This soup isn't very nice. (it / taste) better if it wasn't so salty.
  5. We live in a city and don't need a car, but we would need one if (we / live) in the country.
  6. If we had the choice, (we / live) in the country.
  7. I'd make a lot of changes if (I / be) the manager of the company.
  8. I wouldn't call someone in the middle of the night if (it / not / be) important.
  9. If I were you, (I / not / wait). (I / go) now.
  10. You're always tired because you go to bed so late. If (you / not / go) to bed so late every night, (you / not / be) tired all the time.
  11. I think there are too many cars. If (there / not / be) so many cars, (there / not / be) so much pollution.
  12. We all need jobs and money, but what (you / do) if (you / not / have) to work?
Exercise 39.2 5 items • Write sentences with if …

Write a sentence with if … for each situation.

  1. We don't see you very often because you live so far away.
  2. I like these shoes but they're too expensive, so I'm not going to buy them.
  3. We'd like to go on holiday, but we can't afford it.
  4. It would be nice to have lunch outside but it's raining, so we can't.
  5. I don't want his advice, and that's why I'm not going to ask for it.
Exercise 39.3 9 items • Write sentences beginning I wish …

Write sentences beginning I wish … to express regrets about present situations.

  1. I don't know many people (and I'm lonely).
  2. I don't have much free time (and I need more).
  3. Helen isn't here (and I need to see her).
  4. It's cold (and I hate cold weather).
  5. I live in a big city (and I don't like it).
  6. I can't find my phone (which is a problem).
  7. I'm not feeling well (which isn't good).
  8. I have to get up early tomorrow (but I'd prefer to sleep late).
  9. I don't know much about science (and I should know more).
Exercise 39.4 4 items • Write your own sentences with I wish …

Write your own sentences beginning I wish … based on the prompts.

Answers with Full Explanations

Exercise 39.1 — Key & Explanations
  1. knew (example)
  2. I wouldn't buy (example)
  3. I'd help / I would help — imaginary result: would + base form.
  4. It would taste / It'd taste — result clause.
  5. we lived — if-clause requires past simple.
  6. we'd live / we would live — result clause.
  7. I was / I were — both are acceptable after if I.
  8. it wasn't / it weren't — negative past in if-clause.
  9. I wouldn't wait ... I'd go / I would go — advice structure.
  10. you didn't go ... you wouldn't be — condition + result.
  11. there weren't ... there wouldn't be — hypothetical state.
  12. would you do if you didn't have — question inversion.
Exercise 39.2 — Key & Explanations
  1. If you didn't live so far away, we'd see you more often. (example)
  2. I'd / I would buy them if they weren't / wasn't so expensive.
  3. We'd / We would go on holiday if we could afford it.
  4. We could have lunch outside if it weren't/wasn't raining.
  5. If I wanted his advice, I'd / I would ask for it.
