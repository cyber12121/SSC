Unit 38 • if and wish

if I do … and if I did …Real possibility vs. hypothetical / imaginary conditions

Compare real conditions using the present tense with hypothetical or unlikely situations using if + past.

Learning Objectives

After completing this unit, you will be able to:

  • Distinguish between real future possibilities (if + present, will) and hypothetical situations (if + past, would).
  • Use the past tense after if for imaginary or unlikely present/future events.
  • Ensure would is used in the main clause and never in the if-clause.
  • Incorporate could and might into hypothetical result clauses.

Part A — Theory

A. Real vs. Unreal / Hypothetical Conditions

Compare these two conversations:

1. Real Possibility: if + present, will

Lisa: Shall we take the bus or the train?

Jess: If we take the bus, it will be cheaper.

For Jess, it is possible that they will take the bus, so she uses the present (take) + will.

2. Unreal / Hypothetical: if + past, would

(Later, Lisa and Jess have decided to take the train. Jess talks to Joe:)

Joe: How are you going to travel?

Jess: We're going to take the train. If we took the bus, it would be cheaper, but the train is quicker.

Jess knows they are NOT going to take the bus. She imagines an unreal situation: took + would be.

Key Rule When we talk about something that will not happen, or we don't expect to happen, we use if + past (if we went / if there was / if I found etc.). But the meaning is present or future, not past:
  • What would you do if you won a lot of money? (I don't expect to win)
  • If there was an election tomorrow, who would you vote for? (there will not be an election)
  • I'd be surprised if they didn't come to the party. (I expect them to come)

B. Would in Result Clauses (Not in the If-Clause)

We do not normally use would in the if-part of the sentence:

  • I'd be very scared if somebody pointed a gun at me. (not if somebody would point)
  • If we went by bus, it would be cheaper. (not If we would go)

In the other part of the sentence (the result clause), we use would ('d) or wouldn't:

  • I'm not going to bed yet. I'm not tired. If I went to bed now, I wouldn't sleep.
  • What would you do if you were bitten by a snake?
Could & Might Could (= would be able to) and might (= maybe / perhaps would) are also possible in the result clause:
  • If I won a lot of money, I might buy a house. (= it is possible that I would buy a house)
  • If it stopped raining, we could go out. (= we would be able to go out)

Exercise 38.2 7 items • Choose option a or b

What do you say in these situations? Select option (a) or (b).

  1. Of course you don't expect to win the lottery. Which do you say?
    (a) If I win the lottery, I'll buy a big house. • (b) If I won the lottery, I'd buy a big house.
    (b is correct — you don't expect to win)
  2. You're not going to sell your car because it's old and not worth much. Which do you say?
    (a) If I sell my car, I won't get much money for it. • (b) If I sold my car, I wouldn't get much money for it.
  3. You often see Sarah. A friend of yours wants to contact her. Which do you say?
    (a) If I see Sarah, I'll tell her to call you. • (b) If I saw Sarah, I'd tell her to call you.
  4. You don't expect that there will be a fire in the building. Which do you say?
    (a) What will you do if there is a fire in the building? • (b) What would you do if there was a fire in the building?
  5. You've never lost your passport. You can only imagine it.
    (a) I don't know what I'll do if I lose my passport. • (b) I don't know what I'd do if I lost my passport.
  6. Somebody stops you and asks the way to a bank. Which do you say?
    (a) If you go right at the end of this street, you'll see a bank on your left. • (b) If you went right at the end of this street, you'd see a bank on your left.
  7. You're in a lift. There is an emergency button. Nobody is going to press it. Which do you say?
    (a) What will happen if somebody presses that button? • (b) What would happen if somebody pressed that button?

Answers with Full Explanations

Exercise 38.1 — Key & Explanations
  1. found (example) — imaginary finding in the street.
  2. dropped — hypothetical action: If you dropped it...
  3. lost — If I lost it, I'd be very upset.
  4. happened — if that happened, I'd have to find another one.
  5. went — If we went to Italy...
  6. did — short substitution for failed the exam.
  7. was / were — both are correct after if there in hypothetical conditions.
Exercise 38.2 — Key & Explanations
  1. b — you don't expect to win the lottery, so hypothetical (If I won... I'd buy).
  2. b — you're not going to sell your car (If I sold my car, I wouldn't get much money).
  3. a — you often see Sarah, so it is a real possibility (If I see Sarah, I'll tell her).
  4. b — you don't expect a fire (What would you do if there was a fire).
  5. b — you've never lost it, only imagining (I don't know what I'd do if I lost my passport).
  6. a — realistic directions given to a passerby (If you go right... you'll see).
  7. b — nobody is going to press it, imaginary consequence (What would happen if somebody pressed that button?).
Exercise 38.3 — Key & Explanations
  1. somebody pointed (example) — past form after if.
  2. I bought — If I bought a car, I'd have to borrow the money.
  3. would you invite — question form in the main clause.
  4. he asked — past form in the if-clause.
  5. I'd be / I would be — result clause.
  6. somebody gave ... I'd have / I would have — condition + result.
  7. Would you be ... you met — result question + condition.
  8. would you do ... you were ... it stopped — compound hypothetical scenario.
Exercise 38.4 — Key & Explanations
  1. If we took the 10.30 train, we'd arrive too early. (example)
  2. If we stayed at a hotel, it would cost too much.
  3. If I told you what happened, you wouldn't believe me (or it).
  4. If she left her job, it would be hard to find another one.
  5. If he applied for the job, he wouldn't get it.
