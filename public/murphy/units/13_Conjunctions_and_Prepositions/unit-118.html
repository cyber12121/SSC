Unit 118 • Conjunctions and prepositions

like, as ifsensory impressions, appearance & hypothetical comparisons: look / sound / feel like or as if

We use like or as if (or as though) with look, sound and feel to describe impressions and appearances. We can also use as if + past tense for hypothetical or unreal situations.

Learning Objectives

After completing this unit, you will be able to:

  • Describe appearances and sensations using look / sound / feel like or as if / as though: That house looks like it's going to fall down.
  • Contrast look + adjective (e.g. You look tired) with look like / as if + clause (e.g. You look as if you haven't slept).
  • Form deductions from evidence using It looks like ... and It sounds like ....
  • Use like / as if / as though with other action verbs to describe manner: He ran like he was running for his life.
  • Use as if + past tense to indicate hypothetical or untrue current situations: He talks as if he knew everything / as if he were an old man.

Part A — Theory

Part A: Look, Sound, Feel Like / As If

We use like or as if to say how somebody or something looks, sounds or feels:

• That house looks like it's going to fall down.  or  … looks as if it's going to fall down.
• Amy sounded like she had a cold, didn't she?  or  … sounded as if she had a cold …
• I've just had a holiday, but I feel very tired. I don't feel like I've had a holiday.  or  … feel as if I've had a holiday.

You can also use as though in all these examples:

I don't feel as though I've had a holiday.
look + adjective

You look tired.
(verb + adjective directly)

look like / as if + clause

You look like you haven't slept.
You look as if you haven't slept.
(verb + like / as if + subject + verb)

Part B: It Looks Like ... / It Sounds Like ...

We say it looks like … / it looks as if … and it sounds like … / it sounds as if …:

• Sarah is very late. It looks like she isn't coming. (or It looks as if she isn't coming.)
• It looked like it was going to rain, so we took an umbrella. (or It looked as if it was going to rain ...)
• The noise is very loud next door. It sounds like they're having a party. (or It sounds as if / as though ...)

Part C: Manner With Other Verbs

You can use like / as if / as though with other action verbs to describe how somebody does something:

• He ran like he was running for his life.
• After the interruption, the speaker went on talking as if nothing had happened.
• When I told them my plan, they looked at me as though I was mad.

Part D: As If + Past (Unreal / Hypothetical Situations)

After as if, we sometimes use the past tense when talking about the present:

I don't like him. He talks as if he knew everything.
(The meaning is not past. We use the past because the idea is unreal: he does NOT know everything.)

We do not normally use like in this hypothetical way. More examples:

• She's always asking me to do things for her – as if I didn't have enough to do already.
• Joe's only 40. Why do you talk about him as if he was an old man? (he isn't an old man)

When using the past in this unreal way, you can use were instead of was:

• Why do you talk about him as if he were an old man?
• They treat me as if I were their own son.  or  … as if I was their own son. (I'm not their son)
