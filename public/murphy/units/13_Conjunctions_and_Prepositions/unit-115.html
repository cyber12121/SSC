Unit 115 • Conjunctions and prepositions

unless, as long as, providedconditions & exceptions: unless (= except if), as long as / so long as, provided / providing (that)

Unless means 'except if'. As long as, so long as, provided that and providing that mean 'on condition that' or 'only if'. When referring to the future, we use present tenses after these conjunctions.

Learning Objectives

After completing this unit, you will be able to:

  • Master unless to express exceptions (meaning except if or only if ... not): You can't go in unless you are a member.
  • Rephrase conditional sentences interchangeably between unless and if ... not.
  • Use as long as and so long as to state conditions (on condition that).
  • Use provided (that) and providing (that) in formal and standard registers.
  • Apply the future tense constraint: never use will after unless / as long as / provided (use present tense).

Part A — Theory

Part A: Unless (= Except If)

Study this example situation:

The club is for members only.
You can't go in unless you are a member.
This means:
• You can't go in except if you are a member.
• You can go in only if you are a member.

Some more examples of unless:

• I'll see you tomorrow unless I have to work late. (= except if I have to work late)
• There are no buses to the beach. Unless you have a car, it's difficult to get there.
• ‘Shall I tell Lisa what happened?’ ‘Not unless she asks you.’ (= tell her only if she asks)
• Ben hates to complain. He wouldn't complain about something unless it was really bad.
• We can take a taxi to the restaurant – unless you'd prefer to walk.

Instead of unless, it is often possible to say if … not:

Unless we leave now, we'll be late.  or  If we don't leave now, we'll be late.

Part B: As Long As, So Long As, Provided, Providing

You can say as long as or so long as (= if, on condition that):

You can borrow my car as long as you promise not to drive too fast.
or … so long as you promise not to drive too fast.
(= You can borrow my car, but you must promise not to drive fast. This is a condition.)

You can also say provided (that) or providing (that):

• Travelling by car is convenient provided (that) you have somewhere to park. (or providing that ...)
• Providing (that) the room is clean, I don't mind which hotel we stay at. (or Provided that ...)
as long as / so long as

Very common in everyday spoken English: as long as you promise.

provided (that) / providing (that)

Common in both speech and writing: provided the weather is good.

Part C: Unless / As Long As etc. for the Future

When we are talking about the future, we do NOT use will after unless / as long as / so long as / provided / providing. We use a present tense:

• I'm not going out unless it stops raining. (NOT unless it will stop)
• Providing the weather is good, we're going to have a picnic tomorrow. (NOT providing the weather will be good)
