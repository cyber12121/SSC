Unit 114 • Conjunctions and prepositions

in caseexpressing precaution: in case + present/past, just in case, in case vs if, in case of

We use in case to say that somebody does something now because it is possible something else will happen later. We do not use will after in case.

Learning Objectives

After completing this unit, you will be able to:

  • Understand in case as a precaution against future possibilities: Take an umbrella in case it rains.
  • Apply the tense rule: never use will after in case (use present tense for future).
  • Use just in case for smaller possibilities: I don't think it will rain, but I'll take an umbrella just in case.
  • Distinguish between in case (do action now whether it happens or not) and if (do action only if it happens).
  • Use in case + past to explain why somebody did something in the past.
  • Recognize in case of + noun (= if there is ...) in public notices and safety instructions.

Part A — Theory

Part A: In Case = Because It Is Possible Something Will Happen

Study this example situation:

Your car should have a spare wheel in case you have a puncture.
(= because it is possible you will have a puncture)

We use in case to say why somebody does (or doesn't do) something. You do something now because of something that might happen later:

• I'd better write down my password in case I forget it. (= because it is possible I will forget it)
• Shall I draw a map for you in case you have a problem finding our house?
• I'll remind them about the meeting in case they've forgotten.

We use just in case for a smaller possibility:

I don't think it will rain, but I'll take an umbrella just in case. (= just in case it rains)
Tense Rule: Do not use will after in case:
I'll write down my password in case I forget it. (NOT in case I will forget)

Part B: In Case vs If

In case and if are not the same:

in case (precaution now)

We'll buy some more food in case Tom comes.
(= Maybe Tom will come. We'll buy food now, whether he comes or not. Then we'll already have the food if he comes.)

I'll give you my phone number in case you need to contact me.

You should insure your bike in case it is stolen.

if (conditional action later)

We'll buy some more food if Tom comes.
(= Maybe Tom will come. If he comes, we'll buy food. If he doesn't come, we won't buy any more food.)

You can call me on this number if you need to contact me.

You should inform the police if your bike is stolen.

Part C: In Case + Past Tense

You can use in case + past to say why somebody did something in the past:

• I gave him my phone number in case he needed to contact me. (= because it was possible that he would need to contact me)
• I drew a map for Sarah in case she had a problem finding our house.
• We rang the doorbell again in case they hadn't heard it the first time.

Part D: In Case Of (+ Noun)

In case of = if there is … (especially on notices, instructions, signs):

• In case of fire, please leave the building as quickly as possible. (= if there is a fire)
• In case of emergency, call this number. (= if there is an emergency)

Summary & Quick Reference

Key Takeaways for Unit 114

Category Rule Correct Example
in case + presentAction taken now as precaution for future possibility; do not use willI'll take an umbrella in case it rains.
just in caseUsed for a smaller/slight possibilityIt might not rain, but take it just in case.
in case vs ifin case = action done beforehand; if = action done only conditionallyWe'll buy food in case Tom comes vs if Tom comes.
